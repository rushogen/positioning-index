Chapter 03 · The method

How this was measured, and what it will not claim

It refuses to guess. Two public pages per company, what it can read recorded, what it cannot said plainly.

No conversion data, so it reports what is common and never what works. Well-known companies, which is survivorship, not quality. Section types come from a classifier right about half the time off the hero; every figure that rests on it is marked. Unread is counted as unread, never as absence. Each crawl is a timestamped commit, so a number you cite traces to the bytes behind it — the full methodology and the corrections log are public.

What has moved since the archive started

This is the slow half of the project and it is deliberately quiet. A change is published only when the page was read successfully, from the same place as last time, and the value moved from one known value to another. A failed extraction, a redesign, or a crawl run from a different country produces an observation and no claim — a broken selector is not a repositioning, and a price quoted in a different currency because the request came from a different continent is not a price change.       About this index

      What it measures

      Twelve signals per company: hero headline and subhead, the category noun, meta title and description, customer logo names, quantified proof points, and from the pricing page the tier list, entry price, whether a free tier is published, and any seat minimum.

      Methodology, v1.4 · Corrections

      How it crawls

      Public marketing pages only, at most one request per page per day, from a named user agent that links back to a disclosure page. robots.txt is honoured per RFC 9309 including Crawl-delay, and Content-Signal declarations are honoured too. If robots.txt cannot be read, nothing is fetched.

      Crawler disclosure and opt-out

      Where it lives

      Nothing here is hosted infrastructure. A crawl is a command someone runs; the result is committed as newline-delimited JSON, and this page is generated from those files. Not a scraper of anything behind a login, not a rented API a policy change can switch off, and not a claim that any change was strategic — it records what was published, and when.
